# Replacement Artifact Storage Policy

Version: 1.0.0

Status: Approved policy; storage not provisioned

Document Type: Research Artifact Storage Policy

Architecture Baseline: ABR-1.0 (Frozen)

## Policy

Replacement artifacts require an approved controlled location, immutable manifest, access control, backup, retention, exact path, byte size, and SHA-256. An ignored local output directory alone is insufficient.

## Final Status

Storage approval does not authorize generation.
