## Review Categories

### Architecture Consistency

Verify:

- Architecture direction is unchanged.
- Module responsibilities are aligned.
- Dependency rules are consistent.

---

### Interface Consistency

Verify:

- Public interfaces have ownership.
- Module boundaries are defined.
- Interface contracts are stable.

---

### Documentation Consistency

Verify:

- Naming conventions are consistent.
- Terminology is aligned.
- Markdown rules pass.
