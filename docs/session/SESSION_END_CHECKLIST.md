# Session End Checklist

Version: 1.0.0

## Evidence Collected

- [ ] Evidence sources recorded.
- [ ] Assumptions separated from facts.
- [ ] Unresolved items recorded.

## Files Reviewed

- [ ] In-scope files listed.
- [ ] Out-of-scope files not modified.

## Files Modified

- [ ] Exact modified files listed.
- [ ] New files listed.
- [ ] Untracked pre-existing files distinguished from session changes.

## Git Verification

- [ ] Branch verified.
- [ ] HEAD verified.
- [ ] Working tree verified.
- [ ] Staged state verified.
- [ ] Git actions recorded.

## Outstanding Blockers

- [ ] Every blocker has an owner or is marked owner undefined.
- [ ] Deferred decisions remain explicit.

## Next Action

Record one specific next authorized action or state that no action is authorized.

## Authorization Status

Record authorization ID, scope, approval status, expiration, and whether further authorization is required.

## Close-Out Decision

`<COMPLETE | COMPLETE WITH BLOCKERS | STOPPED — AUTHORIZATION REQUIRED>`
