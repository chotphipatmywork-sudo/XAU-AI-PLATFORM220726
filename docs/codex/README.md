# XAU AI PLATFORM CODEX DEVELOPMENT FRAMEWORK

Version: 1.0.0

Status: Active

Architecture Baseline: ABR-1.0

---

## Purpose

This folder defines the Codex development framework for the XAU AI PLATFORM.

The purpose is to standardize Codex-assisted development workflows, protect project architecture, maintain implementation quality, and provide consistent operating rules across development sessions.

---

## Objectives

The Codex framework provides:

- Standardized Codex workflow.
- Architecture protection.
- Consistent implementation quality.
- Controlled AI-assisted development.
- Reduced prompt duplication.
- Improved session continuity.
