# XAU AI PLATFORM CODEX SESSION END CHECKLIST

Version: 1.0.0

Status: Standard

Architecture Baseline: ABR-1.0

---

## Purpose

This checklist defines the required actions and verification steps before ending a Codex development session.

The purpose is to ensure that all completed work is documented, validated, and ready for the next development stage or project review.

---

## Scope

This checklist applies to all Codex-assisted development sessions, including:

- Code implementation.
- Code modification.
- Refactoring.
- Documentation updates.
- Technical analysis tasks.

---

## Required Final Report

Before ending a session, Codex must provide:

- Completed tasks.
- Files created.
- Files modified.
- Files deleted.
- Implementation summary.
- Verification results.
- Known issues.
- Remaining work.
- Next steps.

---

## Verification Checklist

Before session closure, verify:

- [ ] Build completed.
- [ ] Tests completed when applicable.
- [ ] No unexpected file changes exist.
- [ ] Documentation updated when required.
- [ ] Git status reviewed.
- [ ] Remaining issues recorded.

---

## Session Closure Rules

A session is considered complete only when:

- Final report is provided.
- Verification status is available.
- Known issues are documented.
- Next steps are identified.

---

## Completion Criteria

The session closure process is complete when all required reporting and validation activities have been performed.
