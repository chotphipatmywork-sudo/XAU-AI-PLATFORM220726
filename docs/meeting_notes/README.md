Version: 1.0.0

Status: Active

## Purpose

This folder stores project discussion records, review notes, decisions, and important development history for the XAU AI PLATFORM.

The purpose is to provide traceability for important discussions and maintain historical context throughout the project lifecycle.

---

## Scope

This folder may contain records related to:

- Architecture discussions.
- Design reviews.
- Phase reviews.
- Implementation reviews.
- Technical investigations.
- Decision discussions.
- Approval records.

Usage Rules

Meeting notes should:

Record important decisions.
Reference related documents.
Maintain clear dates.
Preserve historical context.

Meeting notes should not:

Replace official specifications.
Override architecture documents.
Replace approved project standards.
Document Authority

The following documents remain authoritative:

Architecture documents.
Specification documents.
Standard documents.
Approved decision records.

Meeting notes provide context only.

Storage Policy

Optional records may remain empty when no meetings or reviews require documentation.

Create records only when they provide long-term project value.
