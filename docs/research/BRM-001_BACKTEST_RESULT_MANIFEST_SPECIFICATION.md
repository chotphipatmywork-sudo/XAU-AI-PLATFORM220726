# BRM-001 Backtest Result Manifest Specification

Version: 1.0.0

Status: Draft — Specification only

Document Type: Offline backtest result manifest specification

Architecture Baseline: ABR-1.0 (Frozen)

## Required Metadata

The manifest includes result schema and metrics versions, event and input identities and hashes, cost configuration and hash, trade and metric counts, output hashes, validation report identity, Git and environment identity, generation command, acceptance state, storage, and backup evidence.

## Immutability

Accepted result files and manifests are immutable, independently backed up, and never silently replaced.
