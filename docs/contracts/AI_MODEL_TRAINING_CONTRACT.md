# AI Model Training Contract

Status: Phase 7 baseline.

## Scope

This contract defines the stable boundary between the offline model-training environment and the future MQL5 inference adapter. It does not select a framework or load a model in the live runtime.

## Model identity

| Field | Value |
|---|---|
| Model name | `XAU_AI_CLASSIFIER` |
| Contract version | `4.0.0` |
| Feature schema version | `4.0.0` |
| Label schema version | `1.1.0` |

## Input tensor

The input name is `features`. Each row contains exactly twelve normalized values in this fixed order:

1. `trend_regime`
2. `trend_momentum`
3. `trend_slope`
4. `volatility_regime`
5. `volatility_change`
6. `liquidity_activity`
7. `liquidity_range_position`
8. `liquidity_sweep_direction`
9. `session_asia`
10. `session_london`
11. `session_new_york`
12. `session_progress`

Values are generated by the canonical historical Brain replay path and normalized by the existing feature normalizer. Risk, confidence, execution, and trade outcomes are not model input features.

Feature Schema 4.0.0 preserves the four canonical groups: Trend, Volatility, Liquidity, and Session. Trend retains its three ATR-normalized horizons. Volatility separates the current ATR regime against the preceding 16 ATR values from its latest short change. Liquidity separates activity, close position inside the preceding 10-bar reference range, and directional sweep encoding where `0/50/100` means buy-side sweep/none/sell-side sweep. Session retains strict one-hot identity and appends `session_progress`, the bounded `0..100` elapsed fraction inside the active eight-hour Session block. The Decision Runtime continues to use unchanged runtime values. Label Schema 1.1.0 remains the calibrated M15 triple barrier of 16 bars and +/- 1.5 ATR(14). Datasets created with earlier feature schemas are incompatible and must not be used to train this contract.

## Label and output mapping

The model is a three-class classifier. CSV labels and output-vector positions are fixed as follows:

| CSV label | Class index | Output name |
|---:|---:|---|
| -1 | 0 | SELL |
| 0 | 1 | HOLD |
| 1 | 2 | BUY |

The output name is `class_probabilities`, ordered `[SELL, HOLD, BUY]`. Every output probability must be within 0..1 and the three values must sum to 1.0 within a tolerance of `0.000001`.

## Boundary rules

- Training reads only the time-split Train/Validation/Test CSV files.
- The future inference adapter must validate this schema and model version before using predictions.
- This contract does not authorize an AI model to bypass AI Decision, Risk, Execution, or Trade Lifecycle.
